onItemClick

  • onItemClick(item): void

  • On item click, the selected item's view is rendered (by routerLink). If the selected item has children items, the menu is updated and view, that is rendered is selected by the defined rule. The rule is: On first check for default view in children. On second check if the clicked item has a view. On third, pick any other children's view, else show nothing.

    Parameters

    • item: NavigationItem

    Returns void
