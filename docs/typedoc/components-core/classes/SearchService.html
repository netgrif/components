ProtectedloadExpressionsIntoPredicate

  • loadExpressionsIntoPredicate(predicate, items): Observable<void>[]

  • Recursively loads an array of query items (expressions and logical operators) into a predicate node.

    Processes each query item in the array:

    • For simple expressions: loads them as individual predicates using loadSimpleExpressionIntoPredicate
    • For complex expressions: recursively processes their nested items
    • For raw expressions: loads them as plain query predicates using loadPlainQueryIntoPredicate
    • Logical operators are filtered out and not processed

    Parameters

    • predicate: EditableClausePredicateWithGenerators

      the predicate node into which the query items should be loaded

    • items: QueryItem[]

      array of query items to process and load into the predicate tree

    Returns Observable<void>[]

    an array of observables that emit when each category's data has been loaded from its expression

    • Defined in projects/netgrif-components-core/src/lib/search/search-service/search.service.ts:406
