# Netgrif Frontend

Functional frontend of [Netgrif Application Engine](https://github.com/netgrif/application-engine) built on the
`@netgrif/components` and `@netgrif/components-core` libraries of this repository: login, navigation drawer,
case / task views, dashboards, profile and process builder, with the Material 3 design of the libraries.

## Requirements

| Name | Version |
|------|---------|
| [Node.js](https://nodejs.org) | 22.22+ or 24.15+ (see `.nvmrc`) |
| Netgrif Application Engine | running backend, address in `nae.json` |

## Development

```shell
npm i --legacy-peer-deps      # @netgrif/petriflow.svg 1.1.1 still declares older Angular peers
npm run frontend:start:full   # builds both libraries, links them into node_modules and serves the app
npm run frontend:start        # serves the app against already built libraries (dist/)
npm run frontend:build        # production build to dist/netgrif-frontend
```

## Configuration

- `nae.json` – engine address, views, navigation and providers (`autoResolveBackendUrl` uses `location.origin + '/api'`)
- `src/styles.scss` – theme, `@include nae.theme()` from `@netgrif/components/theming` (own palettes can be passed
  as `$primary` / `$tertiary`, generated by `ng generate @angular/material:theme-color`)
- `src/app/app.module.ts` – `provideNaeMaterialDefaults({iconFontSet: 'material-symbols-rounded'})`
  (the Material Symbols font is loaded in `src/index.html`)
